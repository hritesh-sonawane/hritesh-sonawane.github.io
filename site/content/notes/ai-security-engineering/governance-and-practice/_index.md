Controls only work inside an organization that knows what it is running, tests
it on purpose, and can show its work. This module covers the obligations an
engineering team answers to, the red-team program that keeps findings fixed,
and a complete security design that pulls the whole course together.

By the end of it you should be able to classify an AI system under the EU AI
Act, map one set of controls to several frameworks, run a red-team program
whose results are measured in code, and defend a layered design for an agent
platform: which layer stops what, which layers are deterministic, and what risk
remains.
