Large models are built from a few simple operations repeated at enormous scale.
This course follows them from a single gradient to a training run across
thousands of GPUs: what the mathematics asks for, what the hardware can deliver,
and where the two meet.

It assumes you can read Python and remember a little linear algebra. It does
**not** assume a machine-learning background.

## What you need

- Python 3.10 or newer. Programs use only the standard library and run offline;
  GPU behavior is simulated with arithmetic.
